## Overview

Vision Transformers (ViTs) increasingly power safety-critical visual recognition
systems, yet remain vulnerable to backdoor attacks, and existing post-training
defenses — predominantly designed for convolutional networks — transfer to ViTs
with mixed effectiveness.

**FilterShield (FS)** is a lightweight *post-training* backdoor defense for ViTs.
It inserts a **single learnable linear projection** into the token sequence,
immediately before the first layer of *global* attention, suppressing trigger
signals before they propagate irreversibly through the network. The projection is
trained on only **10% clean data** using **attack-agnostic proxy triggers** and a
**multi-objective adversarial loss**, while *all* original model parameters remain
frozen.

**Design principle (transferable across architectures).** Insert the projection
where attention first becomes global:
- block `-1` (the boundary before the first global-attention block) for DeiT / ViT;
- the stage-3 boundary for Swin Transformer, where windowed attention first covers
  the full feature map.

The defense is *attack-agnostic*: it does not need to know the target class or the
attacker's trigger. During training, lightweight proxy triggers (visible patches,
invisible patch noise, local texture blobs, …) are randomly injected and a strong
PGD attacker exposes vulnerable directions, so the projection `P` learns to filter
trigger-like artifacts while staying close to identity to preserve clean accuracy.

> Reported in the paper: on CIFAR-10 with DeiT-tiny, FS reduces the average attack
> success rate (ASR) from 90.09% to **0.81%**, outperforming six baselines by
> 35–79 percentage points, and generalizes to Tiny-ImageNet and Swin-T.

## What is in this repository

This repository contains the **core reference implementation** of FilterShield
and the **six baseline defenses** used for comparison, so the method can be
studied and re-implemented from scratch.

| File | Description |
| --- | --- |
| `deit_tiny_fs_plus_offline.py` | Core implementation: ViT/DeiT/Swin backbones, backdoor attacks (BadNets, WaNet, Blend, SIG, TrojViT, BadViT), the **FilterShield (FS) defense**, training, and evaluation. |
| `baseline_finepruning.py` | Fine-Pruning (Liu et al., RAID 2018), adapted for the ViT family. |
| `baseline_nad.py` | Neural Attention Distillation (Li et al., ICLR 2021). |
| `baseline_anp.py` | Adversarial Neuron Pruning (Wu & Wang, NeurIPS 2021). |
| `baseline_neural_cleanse.py` | Neural Cleanse (Wang et al., S&P 2019). |
| `baseline_rnp.py` | Reconstructive Neuron Pruning (Li et al., ICML 2023). |
| `baseline_patch_processing.py` | Patch Processing test-time defense (Doan et al., AAAI 2023). |

The baseline scripts import shared model / attack / data utilities from
`deit_tiny_fs_plus_offline.py`; keep all files in the same directory.

### Intentionally not included

To keep the release focused and lightweight, the following are **not** distributed
here. The released code is self-contained and sufficient to reproduce the method;
these items can be regenerated by running the code on standard public datasets.

- **Datasets.** CIFAR-10, GTSRB, and Tiny-ImageNet are publicly available and are
  not redistributed. Point the code at your local copy via `--data`.
- **Trained checkpoints.** Backdoored ("victim") models, trained FS projections,
  and pretrained backbone weights are not included. They are available from the
  authors upon reasonable request for academic purposes.
- **Cluster / experiment-orchestration scripts** and raw result logs used for the
  paper's large-scale sweeps are environment-specific and omitted.

## Requirements

- Python ≥ 3.9
- PyTorch ≥ 1.13 and torchvision (CUDA build recommended)
- [`timm`](https://github.com/huggingface/pytorch-image-models)
- `tqdm`

```bash
pip install -r requirements.txt
```

A pretrained backbone is needed to train a victim model. The code can use a
`timm` ImageNet-pretrained DeiT (online), or a local checkpoint via
`--pretrained_ckpt` together with `--offline` for air-gapped environments.

## Data preparation

Provide the datasets yourself and point `--data` at the root directory.

- **CIFAR-10** — can be downloaded automatically by torchvision (omit `--offline`
  / `--no_download`), or place the standard `cifar-10-batches-py/` under `--data`.
- **GTSRB**, **Tiny-ImageNet** — place under `--data` in their standard layout and
  select with `--dataset gtsrb` / `--dataset tiny_imagenet`.

## Usage

The pipeline has three stages: (1) train a backdoored victim, (2) train the
FilterShield projection on clean data, (3) evaluate Clean ACC and ASR. The
following examples use DeiT-tiny on CIFAR-10 with the TrojViT attack.

### 1. Train a backdoored victim model

```bash
python deit_tiny_fs_plus_offline.py --task train_victim \
  --data ./data --dataset cifar10 --model deit_tiny --pretrained \
  --attack trojvit --target 0 --poison_rate 0.1 \
  --epochs 100 --save victim_trojvit.pth
```

### 2. Train FilterShield (defense) on 10% clean data

```bash
python deit_tiny_fs_plus_offline.py --task train_fs \
  --data ./data --dataset cifar10 --model deit_tiny \
  --victim_ckpt victim_trojvit.pth --save_fs fs_trojvit.pth \
  --clean_fraction 0.10 --fs_epochs 15 \
  --fs_after_block -1 --fs_split_cls \
  --eps 0.047 --alpha 0.007 --steps 20 \
  --lambda1 1.0 --lambda_consistency 1.0 --lambda_entropy 0.5 --lambda3 1e-4 \
  --proxy_triggers_prob 0.5
```

Key defense hyper-parameters:

| Argument | Meaning |
| --- | --- |
| `--clean_fraction` | Fraction of clean training data available to the defender (paper uses 0.10). |
| `--fs_after_block` | Insertion point; `-1` = before the first global-attention block (DeiT/ViT). |
| `--fs_split_cls` | Apply the projection to patch tokens with separate handling of the CLS token. |
| `--eps`, `--alpha`, `--steps` | PGD budget / step size / iterations for exposing vulnerable directions. |
| `--lambda1` | Weight of the adversarial cross-entropy term. |
| `--lambda_consistency` | Weight of the clean–adversarial logit consistency (KL) term. |
| `--lambda_entropy` | Weight of the entropy term that discourages single-class collapse. |
| `--lambda3` | Weight of the `‖P − I‖²` regularizer keeping `P` near identity. |
| `--proxy_triggers_prob` | Probability of injecting an attack-agnostic proxy trigger per batch. |

### 3. Evaluate

```bash
python deit_tiny_fs_plus_offline.py --task eval \
  --data ./data --dataset cifar10 --model deit_tiny \
  --victim_ckpt victim_trojvit.pth --fs_ckpt fs_trojvit.pth \
  --attack trojvit --target 0
```

### Baselines

Each baseline takes a backdoored `--victim_ckpt` and reports Clean ACC / ASR after
its purification. For example, ANP:

```bash
python baseline_anp.py \
  --victim_ckpt victim_trojvit.pth --data ./data --dataset cifar10 --model deit_tiny \
  --clean_fraction 0.10 --anp_epochs 20 --mask_threshold 0.4 --ft_epochs 3 \
  --attack trojvit --target 0
```

Run any baseline with `--help` for its full argument list. Supported attacks
across the suite: `badnets`, `wanet`, `blend`, `sig`, `trojvit`, `badvit`, `issba`.
Supported models: `deit_tiny`, `deit_small`, `deit_base`, `vit_b16`, `swin_t`.
